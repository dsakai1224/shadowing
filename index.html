Shadowing Studio

Gemini TTS で発音・イントネーション・区切りを確認する
スタイル指示は生成時にモデルへ渡されます。「ゆっくり明瞭」と「自然な会話速度」を同じ文で聴き比べるのが、 リンキングや音の脱落を掴む上で一番効きます（各文の「比較」ボタン）。
再生速度はブラウザ側でピッチを保ったまま変えるので、音質を壊さずスローダウンできます。 キーボード：Space 現在の文を再生 / J 次の文 / K 前の文
設定（API キー・モデル）
キーはこのブラウザの localStorage にのみ保存され、リポジトリにもサーバーにも送られません。 通信先は generativelanguage.googleapis.com のみです。 共有PCでは使わず、キーには Google Cloud 側で使用量上限を設定してください。
API キーの取得：Google AI Studio →「Create API key」。無料枠があります。
