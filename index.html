Shadowing Studio

Gemini で発音・イントネーション・区切り・語彙を確認する
スタイル指示は生成時にモデルへ渡されます。「ゆっくり明瞭」と「自然な会話速度」を同じ文で聴き比べるのが、 リンキングや音の脱落を掴む上で一番効きます（各文の「比較」ボタン）。
再生速度はピッチを保ったまま変速するので、音質を壊さずスローダウンできます。 再生中は画面が自動でスリープしないようにします。 キーボード：Space 現在の文 / J 次 / K 前 / Esc 停止
設定（API キー・モデル）
キーはこの端末のブラウザ（localStorage）にのみ保存され、リポジトリにもサーバーにも送られません。 通信先は generativelanguage.googleapis.com だけです。 端末ごとに入力が必要です。共有端末では使わず、Google Cloud 側で使用量上限を設定してください。
キーの取得：Google AI Studio →「Create API key」。
※ Google AI Pro の契約は AI Studio 内でのみ有効で、この API 呼び出しは別会計です。
準備完了。まず設定で API キーを保存してください。
