Shadowing Studio

Gemini で発音・イントネーション・区切り・語彙を確認する
語句は常に TOEIC 500 基準でまとめて取得し、表示レベルを上げると不要な項目が消えていきます。 レベル変更で取り直しは発生しません。
再生速度はピッチを保ったまま変速するので、音質を壊さずスローダウンできます。 再生中は画面が自動でスリープしないようにします。 キーボード：Space 現在の文 / J 次 / K 前 / Esc 停止
設定（API キー・モデル）
キーはこの端末のブラウザ（localStorage）にのみ保存され、リポジトリにもサーバーにも送られません。 通信先は generativelanguage.googleapis.com だけです。 端末ごとに入力が必要です。共有端末では使わず、Google Cloud 側で使用量上限を設定してください。
課金されない確実な方法は、モデル選択ではなく Google Cloud 側の設定です。 そのプロジェクトで Cloud Billing を有効化しなければ、どのモデルを選んでも請求は発生しません。 無料枠のないモデルを呼んだ場合は、課金される代わりにエラーが返ります。
また無料枠では入出力が Google の製品改善に利用されます。業務上の非公開情報は貼らないでください。
キーの取得：Google AI Studio →「Create API key」。 実際のレート上限は AI Studio のレート制限ページで確認できます。
※ Google AI Pro の契約は AI Studio 内でのみ有効で、この API 呼び出しは別会計です。
